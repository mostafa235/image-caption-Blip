# BLIP Web Image Captioning

This project extracts images from any website and generates captions for them using the BLIP model from Hugging Face. 
The application is built with Python and provides a Gradio interface for easy interaction.

## Features
- Extracts all images from a given webpage URL
- Ignores SVG and very small images
- Generates captions using BLIP large model
- Displays images and captions in a Gradio gallery
